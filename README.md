# Introduction to R

<br>

This course introduces R and statistical programming.

The course consists of 2 sessions: the first on basic R data types and data input/output, and the second on conditional branching, loops, functions and scripts.
Each session is presented as HTML slides and as a single-page document. Exercises and answer sheets are included after each subsection to practice techniques and to provide future reference examples.

Course material and exercises are available to view as rendered HTML at https://rockefelleruniversity.github.io/Intro_To_R_1Day/.
All material is available to download under GPL v2 license.
